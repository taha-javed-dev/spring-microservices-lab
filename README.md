# Microservices Learning Project

This repository is built for learning Microservices using Spring Boot.

The focus is on understanding core concepts such as:

* Service-to-Service Communication (OpenFeign)
* API Gateway
* Service Discovery
* Circuit Breaker, Retry, Rate Limiter
* Service Workflows

For simplicity, production-level concerns like comprehensive exception handling, input validation, security, logging, and testing are intentionally kept minimal. The primary goal is to learn microservices architecture and concepts through hands-on implementation.
